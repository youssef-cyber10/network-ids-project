# 🛡️ Network Intrusion Detection System (NIDS) بالذكاء الاصطناعي

نظام يكشف الهجمات السيبرانية في حركة الشبكة باستخدام تعلم الآلة، مع واجهة تفاعلية تعرض النتائج لحظيًا.

## المشكلة

الأنظمة التقليدية القائمة على القواعد الثابتة (Signature-based) بتفشل في كشف الهجمات الجديدة (Zero-day) لأنها بتعتمد على أنماط معروفة مسبقًا. الحل: موديل تعلم آلة بيتعرف على **سلوك** الهجوم مش بس **توقيعه**.

## البيانات

- **NSL-KDD** — نسخة محسّنة من KDD Cup 99، معتمدة عالميًا كمعيار قياسي (benchmark) لأبحاث كشف الاختراقات
- 125,973 سجل تدريب، 22,544 سجل اختبار
- 41 خاصية شبكية (مدة الاتصال، البروتوكول، البايتات المرسلة... إلخ)
- 4 فئات هجوم رئيسية: **DoS** (حجب خدمة)، **Probe** (استطلاع)، **R2L** (وصول عن بعد)، **U2R** (تصعيد صلاحيات)

## طريقة التشغيل

```bash
pip install -r requirements.txt
python data/download_data.py      # تحميل البيانات (مرة واحدة)
python src/train.py                # تدريب الموديل
streamlit run dashboard/app.py     # تشغيل الواجهة
```

## النتائج الحالية (Baseline)

| المقياس | Normal | Attack |
|---|---|---|
| Precision | 0.65 | 0.97 |
| Recall | 0.97 | 0.61 |
| F1-score | 0.78 | 0.75 |

**ملاحظة مهمة (نقطة قوة للعرض في المسابقة):** الـ Recall المنخفض نسبيًا على فئة Attack سببه إن NSL-KDD Test set مصمم عمدًا ليحتوي هجمات **غير موجودة إطلاقًا** في بيانات التدريب — وده اختبار حقيقي لقدرة الموديل على التعميم (generalization) مش مجرد حفظ. ده تحديدًا الفرق بين dataset سهل ودataset بحثي معتمد.

## خطوات التطوير القادمة (Roadmap)

- [ ] إضافة موديل Deep Learning (LSTM/Autoencoder) لكشف الأنماط غير المعروفة (zero-day)
- [ ] تصنيف نوع الهجوم (multi-class) مش بس هجوم/طبيعي
- [ ] معالجة اختلال توزيع الفئات (U2R نادر جدًا: 52 عينة فقط)
- [ ] اختبار الموديل على بيانات حركة شبكة حقيقية (Wireshark capture) وليس dataset جاهز فقط
- [ ] دمج تنبيهات لحظية عبر Telegram/Email

## لماذا هذا المشروع مناسب للمسابقة

- بيانات معتمدة أكاديميًا (مصداقية علمية)
- تقييم صحيح (Precision/Recall وليس Accuracy فقط — مهم جدًا في أمن المعلومات)
- تحليل نقاط الضعف بصراحة بدل إخفائها (يُظهر فهمًا عميقًا وليس مجرد تطبيق كود)
- واجهة تفاعلية حية تسمح بعرض demo مباشر أمام لجنة التحكيم
